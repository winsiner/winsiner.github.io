🔮 중첩 상태 시각화 비교

셀이 R/B/Y 중첩 상태일 때 어떻게 보여줄까요? 같은 보드, 다른 표현 방식.
1. 도넛 강조
셀 외곽에 확률 도넛, 가운데에 우세 색 미니 마스코트.
중첩 = 도넛+미니 관측됨 = 풀 마스코트
👍 강점확률 분포 명확, 한눈에 우세색 파악, 정적이라 시선 피로 적음
👎 약점"중첩" 느낌은 약함, 다소 정보 그래픽 같음
2. 깜빡임
우세 색 외 다른 색도 살짝 깜빡이며 비침. 우세 색을 라벨로 표시.
중첩 = 3색 순환 깜빡 관측됨 = 풀 마스코트
👍 강점"결정 안 됨" 직관적, 양자 메타포 정확, 시선 강탈
👎 약점시선 피로, 우세색 즉시 파악 어려움, 보드 가득하면 산만
3. 마스코트 흔들림
우세 색 마스코트가 다른 색으로 살짝 변하며 흔들림. "안정되지 않은" 느낌.
중첩 = 우세색 흔들림 관측됨 = 풀 마스코트
👍 강점캐릭터성 살아있음, 귀여움 ◎, 양자 흔들림 메타포
👎 약점다른 색의 비중을 알기 어려움, 흔들림이 보드 가득하면 어지러움
⭐ 4. 도넛 + 흔들림 조합
외곽 도넛으로 확률 표시 + 가운데 마스코트 미세 흔들림. 정보 + 정서.
중첩 = 도넛 + 흔들림 관측됨 = 풀 마스코트
👍 강점확률 정확 + 캐릭터성, 양자 + 캐주얼 동시에, 정보 손실 없음
👎 약점구성 복잡, 작은 셀에서 디테일 안 보일 수 있음
